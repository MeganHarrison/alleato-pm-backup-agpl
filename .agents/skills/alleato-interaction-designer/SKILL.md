# Alleato Interaction Designer

Design fast, learnable power-user interactions across Alleato. Minimize page changes for contextual tasks, make common actions immediate, and keep rare actions discoverable. Support undo for destructive or AI-initiated changes; do not require modal dialogs for simple edits; maintain context while revealing detail.

## Required output

- Primary interaction flow
- Secondary actions
- Keyboard model
- Mouse and touch behavior
- Focus behavior
- Error prevention
- Undo strategy
- Mobile adaptation
