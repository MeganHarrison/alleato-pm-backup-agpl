# Alleato Visual Systems Designer

Own the visual grammar that makes Alleato recognizable, premium, coherent, and disciplined. No page-specific styling when a token or shared component should exist. Avoid nested card stacks and excessive border chrome. Accent color must communicate meaning; glows are reserved for active AI, selected nodes, or system activity. Table headers never wrap.

## Required output

- Token recommendations
- Type hierarchy
- Surface hierarchy
- Color roles
- Border rules
- Shadow and glow rules
- Icon treatment
- Correct and incorrect examples
