# Alleato Experience System

Alleato is an AI-native construction operating system, not a digital filing cabinet or generic project-management template. The goal is shared understanding, coordinated action, and better decisions from fragmented operational activity.

## Use this skill

Use it before implementing an Alleato product surface that requires experience strategy, a new interaction model, a visualization, or a substantial design review. It complements the existing `impeccable` skill: use Impeccable for the Alleato noise gate and shared-pattern rules, then use this system to decide the experience model.

## Core questions

Every important screen must make clear:

1. What is happening?
2. What changed?
3. Why does it matter?
4. What is connected?
5. What should happen next?

Start with the user's decision and context, not cards, containers, or database fields. Treat relationships, evidence, human control, and AI confidence as first-class information when relevant. Prefer progressive disclosure; show essential signal first, then use focused detail, inspectors, expansion, and drill-down.

## Select one primary archetype

- **Command Center** — prioritized actions, exceptions, and contextual drill-down.
- **System Map** — connected agents, objects, or data flows with a relationship inspector.
- **Storyline** — events, material change, cause and effect, evidence, and next action.
- **Workbench** — dense, keyboard-efficient operational work with inline editing and saved views.
- **Structured Form** — clear grouped data entry and review, with a sticky summary only when complexity warrants it.

## Required pre-code UI plan

Produce the page archetype, user objective, primary decision/action, information hierarchy, objects and relationships, layout zones, interaction model, visualization rationale, loading/empty/error/success states, motion plan, mobile behavior, and accessibility considerations. Do not implement from a loose screenshot or feature list alone.

## Specialist sequence

For substantial work, apply these skills in order: `alleato-product-story-designer`, `alleato-experience-architect`, `alleato-data-visualization-designer` when visual data is involved, `alleato-interaction-designer`, `alleato-visual-systems-designer`, and `alleato-motion-designer`. Re-run the Experience Architect as final reviewer.

## Delivery gate

Before approval, confirm the archetype is declared; core states, keyboard behavior, reduced motion, mobile behavior, and source/evidence behavior are defined; and the page does not rely on ornamental cards, duplicate summaries, or visual novelty in place of clarity.
