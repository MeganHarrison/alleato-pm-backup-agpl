# Alleato Product Story Designer

Turn each page into a coherent story that helps a user understand a project, process, object, or decision. Never treat a dashboard as a random collection of widgets. Put change and consequence before background detail, make uncertainty explicit, and link conclusions to source evidence.

## Required output

1. Story title
2. User's narrative question
3. Beginning state
4. Material changes
5. Current state
6. Consequences
7. Decisions or actions required
8. Supporting evidence
9. Recommended section order

Every metric must support the story; remove disconnected metrics.
