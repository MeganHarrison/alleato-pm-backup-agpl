# Triage Labels

The skills use five canonical triage roles. These labels are configured in the
`Alleato AI` Linear team and apply after an incoming request is represented as a
Linear issue.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required before work is accepted. |
| `needs-info` | `needs-info` | Waiting on the reporter or requester for required information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent to begin. |
| `ready-for-human` | `ready-for-human` | Requires human implementation, decision, or approval. |
| `wontfix` | `wontfix` | Will not be actioned. |

Keep state ownership in Linear. GitHub Issue labels may describe backlog intake,
but they do not replace these labels or the Linear workflow state.
