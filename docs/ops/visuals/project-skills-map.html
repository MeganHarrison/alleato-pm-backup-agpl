Five-question check

Route before you read

This is the shortest reliable decision tree for an unfamiliar request. Stop at the first definitive answer and load that owner.

Did the user name a skill? Yes → verify its exact name and path.
Is there an Alleato owner? Yes → project-local guidance wins.
Is AI SDK involved? Yes → load ai-sdk, always.
Is the outcome visible? Yes → add browser and screenshot proof.
Is the boundary high risk? Yes → add the required end-to-end and review evidence.
