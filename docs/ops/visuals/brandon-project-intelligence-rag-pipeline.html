The question determines the route

One assistant. Three evidence strategies.

The system should not vector-search everything. It first identifies the job Brandon is asking it to do, then uses the most authoritative source for that job.

  1. “What changed, and what needs me?”

    →
    Packet-first Use the current Project Intelligence packet.

    Synthesizes current status, change, risk, decisions, promises, and next moves. It declares freshness and coverage; if the packet is thin or stale, it falls back to live source lookup.

  2. “Show me exactly where that came from.”

    →
    Source lookup Retrieve the exact meeting, email, Teams message, or document.

    RAG finds the semantically relevant passages, preserves source identity, and returns a usable citation instead of asking Brandon to trust the summary alone.

  3. “What is the committed cost right now?”

    →
    Structured truth Query the project or accounting system directly.

    Financials, contracts, commitments, RFIs, and schedule status use governed data tools first. Narrative evidence may explain the number, but it does not replace the system of record.

Two stores, one system

Meaning and retrieval stay connected.

The architecture separates operational truth from vector retrieval. The document ID and evidence lineage bridge them, so a semantic match can still lead back to the record Brandon can inspect.

The recovery loop

No evidence, no confident brief.

A useful system does not hide missing coverage behind good prose. It identifies the first broken boundary, records it, and takes the smallest recovery action before the intelligence is published.

  1. ×Connector missingRe-sync the source; do not claim complete coverage.
  2. ×Project uncertainHold for attribution review; do not leak evidence across projects.
  3. ×Zero usable chunksRun OCR or the full pipeline; do not tune the prompt around empty retrieval.
  4. ×Packet stale or thinLabel the baseline and run direct source lookup or recompile.
  5. ×Citation cannot resolveBlock publication of the material claim until the evidence link works.

Brandon’s decision rule

Act on the answer only when you can see what it knows, how current it is, and where the claim came from.
