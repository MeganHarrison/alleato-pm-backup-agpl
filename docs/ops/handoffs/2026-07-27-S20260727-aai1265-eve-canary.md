## Implemented

- One `agents/alleato-assistant` Eve root with six load-on-demand executive skills.
- Durable `AssistantTurn` execute/observe boundary with immutable idempotency,
  replay, cancellation, delegated Eve locators, approvals, and terminal outcomes.
- Atomic turn-version, event-ledger, and approval persistence through
  `persist_durable_ai_turn_transition_v2`.
- Authenticated Eve proxy used by AI Assistant and Ask Alleato.
- Exact, RLS-accessible project resolution before scoped tools; ambiguous names
  fail with user input instead of fuzzy selection.
- One request-scoped tool catalog shared by advertisement and execution.
- Tool bridge authorization is bound to the authenticated durable turn and its
  server-written assistant surface.
- The standalone Eve origin requires a timing-safe server-to-server proxy
  secret and independently revalidates the RLS-visible turn owner and surface.
- Ask Alleato persists Eve conversation, event, and stream state for reconnect,
  scoped by the authenticated user.
- Reversible per-surface/cohort canary with legacy retained as rollback runtime.
- Paired Eve-versus-legacy parity contract covering quality, sources, failure
  signatures, terminal outcome, latency, cost, and effects.
- Direct OpenAI provider support when `OPENAI_API_KEY` is present; gateway model
  IDs remain intact for non-OpenAI/provider configurations.
- Vercel sandbox remains pinned with `deny-all` network policy.
- The main proxy now supplies its trusted Supabase origin and public anonymous
  key to Eve under the server-to-server proxy-secret boundary, preventing the
  two independently deployed services from drifting onto different databases.

## Failure-loudly behavior

Authorization, project resolution, source/tool failures, approvals, event
sequencing, runtime failures, and terminal classification are persisted or
returned as typed failures. Recovery is to set Eve cohort assignment to zero,
allow existing turns to reach terminal state, and route new turns to legacy.
