## Incident Learning

- Failure fingerprint: `ai.tool-approval-secret-empty`
- Root cause: the encrypted Vercel variable existed with a zero-byte value, so presence-only configuration looked healthy while the AI SDK approval runtime rejected action tools.
- Detection gap: no authenticated action-tool smoke followed the environment setup.
- Prevention: configure at least 32 random bytes in every Vercel target, redeploy, and run an authenticated confirmed=false action-tool turn.
- Guardrail evidence: `docs/ops/evidence/2026-07-20-prime-contract-chat-workbook-e2e/runtime-readback.md` plus the shared approval-policy tests.
