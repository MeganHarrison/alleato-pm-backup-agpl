# Noise Gate Log

A running catalog of every UI element Megan has flagged as **visual noise**, why it was noise, and the durable rule extracted from it. This is a learning system: each entry must become a rule that prevents the same class of noise from shipping again.

**Protocol (for any agent doing frontend work):**
1. **Read this log before adding any UI.** Treat every rule below as binding — the burden of proof is on addition.
2. **When Megan calls something "noise" / "visual noise" / "clutter" / "remove this," append a new row here in the same turn**, then apply the fix. Use the next sequential ID. Convert the specific complaint into a general rule.
3. Cross-link to the matching memory file so future sessions load the rule automatically.

This complements the Alleato product noise gate in `CLAUDE.md` and `.agents/skills/impeccable/reference/alleato-product-noise-gate.md`. The gate is the philosophy; this log is the case law.

## Standing rules, distilled

- Secondary add action → bare plus icon, never a labeled/bordered button.
- Never stack a subtitle under a label. One attribute, one place. **In tables this is absolute** — a cell renders one value; a second attribute earns its own column, or moves to a hover `title` tooltip, or is deleted. Enforced by ESLint `design-system/no-stacked-table-cell`, which covers **both** raw stacked `<div>`s **and** the `<CellStackText secondary=…>` primitive (the component that hid the pattern from the lint walk the first time).
- **A full-bleed table's page title aligns with its first column, not the container padding.** Set `alignHeaderWithFullBleedTable` so the header + toolbar pull out by the same margin as the full-bleed table; a title floating right of column one is drift.
- No decorative icons. Icon only when it is the sole affordance.
- Empty field → render nothing, never a dash.
- Sections: spacing + optional thin divider only. No background fills, no borders, no card wrappers.
- Content bodies (message threads, etc.): render directly, spacing only. No card/border wrapper, no bordered header bar.
- No duplicated data and no value-less counts. A datum appears once; never render an item/message count as a heading.
- Embedded relationship/link sub-sections on a detail page → compact field (label + add affordance only when empty), never a full `EmptyState` hero. Selected items list beneath.
- No decorative icon before a panel/sheet/section title; the title stands alone. **Never use the `ExternalLink` icon** — a "view/go to" link uses a plain `ArrowRight`. Enforced by ESLint `design-system/no-external-link-icon`.
- **Sidebar sheet/panel headers own their own styling (including border) in the shared component — never at the callsite.** No `border-b`/`border-t` className overrides on `SheetHeader`/`SidePanelHeader`. Enforced by ESLint `design-system/no-sheet-header-border`.
- No explanatory subheading restating what a panel obviously does. Delete it.
- Utility/media actions in a panel → icon buttons (`icon-sm`, ghost, tooltip), never large labeled outline buttons.
- Embedded tool toolbars → one clean rounded pill (ghost icon buttons, `bg-muted` active state, `w-px` separators), minimal and modern — never dated `border-r` segmented groups.
- **No card-within-card.** Inside a panel/sheet/section, content is plain typography + spacing; a border is earned only by interaction.
- **Never permanently display once-needed information.** No "About X" boxes in workflows — `?` tooltip or docs link at most; data outranks explanation.
- **All type comes from the scale.** No ad-hoc hero numbers; a drilldown summary is one caption+value line. Hero metrics live only in `KpiBlock`/`KpiRow` on dashboards.
- **Never ship a tab/button/link to a placeholder.** No destination → no affordance.
- **Prefer composition over invention.** A new component must solve a new *interaction* problem, never restyle familiar information. Compose from existing primitives first.
- **An empty state contains its primary input and nothing else.** No secondary links under a composer — if the destination exists elsewhere in the app, don't restate it here. When a secondary element is flagged on one breakpoint, delete it rather than gating it behind `md:`.
- **A hero visualization owns its full row.** No companion side rail beside a focal diagram/map/chart — secondary modules stack below it, full width.
- **Never render a chart, trendline, or progress bar for a value the system cannot measure.** An unmeasured metric states its reason in muted body text at context size — never a hero-size "Not measured", never a 0%-wide bar, never a decorative sparkline.
- **Micro-type titles (uppercase, ≤0.7rem) use the body face, never the display face — and are off-white, never accent-tinted.** Accent color on a heading reads as a link and loses contrast on a dark ground.
- **A stat strip is dividers + spacing, not cards.** Hairline `border-left` between tiles; no fill, no border box, no radius.
- **Group actions by role; collapse variants; label for the end user.** Variants of one action → one labeled dropdown with plain-language per-option descriptions, not peer buttons. Separate assist/generate from Save/Cancel with a divider. No internal/model jargon in labels ("deep read", "gpt-5.5") — name the outcome in the user's words.
