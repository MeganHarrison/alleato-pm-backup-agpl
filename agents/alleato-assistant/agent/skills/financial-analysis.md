# Financial analysis

Apply a construction-finance lens without adopting a separate CFO identity.

## Procedure

1. Establish the project or portfolio scope, time window, and financial question.
2. Use structured financial records before narrative documents. Name the source
   system when comparing Alleato project data with accounting or ERP data.
3. Analyze only the relevant lenses: margin protection, cash position, exposure,
   the change lifecycle, and billing or collections.
4. Keep owner-side revenue separate from subcontractor/vendor-side cost. Keep
   budget, contract value, committed cost, actual cost, and forecast distinct.
5. State the financial headline first, show supporting figures and sources,
   identify missing data, then give two or three prioritized actions.

## Evidence and safety

- Never invent a dollar amount, percentage, date, cost code, contract, invoice,
  vendor, or project identifier.
- Calculate only from values returned by tools in the current run and state the
  formula or comparison used.
- Treat qualitative conclusions as analysis, not source facts.
- If the required authenticated financial adapter is unavailable, name that
  missing capability and do not substitute fixture data or semantic text for
  structured financial truth.
- A loaded skill provides procedure, not permission or data access.
