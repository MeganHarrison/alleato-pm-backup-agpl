# Docs Freshness Maintainer

Eve agent package that keeps Alleato's auto-generated and gate-tracked
architecture docs in sync with the code and database. It orchestrates the
EXISTING generators and gates; it does not author docs or replace a generator.

Sibling of `agents/project-intelligence-maintainer/` — same house pattern
(read-only inspection tools, approval-gated mutation, report-only schedule,
redaction, compact failure contract, evals).

## Source of truth

- `docs/architecture/PROJECT-MAP.md` — generated by `npm run map:project`
  (`scripts/dev-tools/generate-project-map.mjs`)
- `docs/architecture/TABLE-LIST.md` — generated by `npm run db:inventory`
  (`scripts/dev-tools/generate-db-inventory.mjs`) from `docs/architecture/tables.yaml`
- `docs/architecture/AI-RAG-ARCHITECTURE.md` — hand-verified; freshness gated by
  RAG-path code change vs its `Last verified: YYYY-MM-DD` line
  (see `.claude/rules/RAG-DOCS-GATE.md`)

## Tools

Read-only:

- `inspect_doc_targets`
- `check_project_map_drift`
- `check_table_inventory_drift`
- `check_rag_docs_staleness`
- `summarize_doc_findings`

Approval-gated:

- `regenerate_generated_docs` — dry-run by default. With `dryRun=false` it leaves
  the regenerated PROJECT-MAP / TABLE-LIST staged in the working tree for a human
  to review and open a PR. It never commits, pushes, or bypasses the pre-commit
  gates.

The read-only drift checks regenerate into a scratch comparison and `git checkout`
the file back, so they never leave the working tree modified. They refuse
(`blocked`) if the target is already dirty.

## Schedule

`agent/schedules/weekday-docs-scan.ts` fires 12:30 UTC on weekdays and is
report-only in v1. Wire a Slack/Teams/Linear channel handoff (eve docs:
Schedules → handler form) before enabling delivery; the tools do not need to
change.

## Failure contract

Every warning, failing, or blocked result reports:

- cause
- detection gap
- prevention step
- owner file(s)
- next action (exact command)

`blocked` specifically covers: a generator that cannot reach its credentials/env
(e.g. `db:inventory` without Supabase access), a dirty target file, or a missing
`Last verified` watermark. Tool outputs are compact and redact common token, key,
DSN, and database-URL patterns.

## What it deliberately does not do

- Does not hand-edit generated docs, `tables.yaml`, or AI-RAG-ARCHITECTURE prose.
- Does not commit, push, merge, or bypass gates.
- For RAG staleness it surfaces the offending commits for a human to verify rather
  than re-writing the architecture doc itself.
